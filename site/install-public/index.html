Abri pelo WhatsApp. Como faço?

Toque em “Copiar link de instalação” e cole no Safari, se estiver no iPhone, ou no Chrome, se estiver no Android. O navegador dentro do WhatsApp pode não oferecer a instalação.

Como instalar no iPhone ou iPad?

Escolha iPhone / iPad e toque em Compartilhar. No menu do Safari que abrir, toque em Adicionar à Tela de Início e depois em Adicionar. Se aparecer Abrir como App da Web, mantenha ativado.

Preciso instalar para usar o MyBot?

Este link é apenas para instalar o MyBot. Depois da instalação, use o ícone criado na tela inicial para abrir o aplicativo.
